# E-Commerce_Sales_Analysis | Power BI

## Project Overview

This project provides a comprehensive view of business performance across sales, customer purchasing behaviour, and teases performance. The objective of this project was to transform raw data into meaningful business insights through interactive reports and data visualisations.

---

##  Project Objectives

- Analyse overall sales performance.
- Identify top-performing Sales Team and Sales Manager
- Track monthly sales trends.
- Evaluate regional sales performance.
- Compare sales against targets using KPIs.
- Build an interactive Reports with dynamic filtering.

---

## Key Insights

- Majority of Target is met. 
- more elder group of customers contributed a significant share of total sales.
- Regional sales performance varied significantly, highlighting opportunities for targeted marketing.
- Sales show similar growth across all months.
- Some Managers did exceptional work in Sales.
